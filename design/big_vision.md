# נתיב: החזון הגדול

נתיב יהיה מערכת שמקבלת כל פנייה של תושב לרשות המקומית, בכל ערוץ ובכל שפה, ומביאה אותה מיד לגורם הנכון ברשות, עם כל הפרטים ועם עדכון לתושב לאורך הדרך.

## סוגי משתמשים ויכולות

| משתמש | יכולות |
|---|---|
| תושב | לדווח על מפגע במילים שלו, בטקסט, בתמונה או בהודעה קולית |
| | לפנות דרך אתר, אפליקציה או וואטסאפ, בעברית, ערבית, רוסית או אנגלית |
| | לענות על שאלות הבהרה עד שהפנייה מלאה |
| | לקבל אישור על פתיחת הפנייה ועדכוני סטטוס עד הסגירה |
| מוקדן | לראות תור פניות שממוין לפי דחיפות |
| | לקבל לכל פנייה הצעת ניתוב, סיכום ודירוג דחיפות |
| | לטפל ידנית בפניות שהמערכת לא בטוחה בהן |
| מחלקת ביצוע | לקבל רק משימות ששייכות למחלקה, עם כתובת, סוג מפגע ותמונה |
| | לעדכן סטטוס טיפול, שמועבר אוטומטית לתושב |
| הנהלת הרשות | לראות מפה של מפגעים חוזרים לפי אזור |
| | לראות זמני טיפול לפי מחלקה |
| | לקבל חיזוי עומסים, למשל לפני חורף |

## יכולות שמשרתות את כולם
- איחוד דיווחים כפולים על אותו מפגע לאירוע אחד.
- למידה מתיקונים של מוקדנים, כדי שהניתוב ישתפר עם הזמן.
